# Data Setup

The analysis expects the external study data to be available in:

```text
data_bitbucket/
```

This directory is not committed to the repository because it contains large study inputs and generated outputs.

## Expected Contents

The scripts reference files such as:

- `data_bitbucket/esets_1_37`
- `data_bitbucket/esets_38_39`
- `data_bitbucket/dataclean.rds`
- `data_bitbucket/total_annotation_all_genes`
- `data_bitbucket/final_results/`
- `data_bitbucket/PAM50_ROR_P/`
- `data_bitbucket/70_gene/`
- `data_bitbucket/oncotype_dx/`
- `data_bitbucket/ggi/`
- `data_bitbucket/Cell_cycle/`

Download the shared data folder linked from the main README and place it at the repository root with this exact name.
